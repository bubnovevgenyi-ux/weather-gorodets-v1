Документация API погоды

HTTP API для доступа к почасовому прогнозу на сегодня и завтра, а также к дневному прогнозу на 10 и 14 дней для Городца. Ответы возвращаются в формате JSON.

Базовый адрес API: /api/v1. Данные формируются парсером Gismeteo и читаются из последнего сохранённого снимка. Все даты и часы прогноза относятся к часовому поясу Europe/Moscow.

Доступные методы

GET
/api/v1/health
Проверка состояния сервиса, доступности прогноза и наличия HTML-копий.
GET
/api/v1/forecast
Полный JSON со всеми четырьмя периодами прогноза и временем последнего обновления.
GET
/api/v1/forecast/{period}
Прогноз для одного периода. Допустимые значения: today, tomorrow, 10_days, 2_weeks.
POST
/api/v1/refresh
Повторно загрузить страницы Gismeteo, выполнить разбор и сохранить новый JSON. Требует заголовок X-Refresh-Token; токен задаётся переменной окружения WEATHER_API_REFRESH_TOKEN.

Примеры запросов

Получить все прогнозы

curl http://localhost:8000/api/v1/forecast

Получить прогноз на 10 дней

curl http://localhost:8000/api/v1/forecast/10_days

Проверить состояние сервиса

curl http://localhost:8000/api/v1/health

Обновить данные (защищённый запрос)

curl -X POST http://localhost:8000/api/v1/refresh \
  -H "X-Refresh-Token: YOUR_REFRESH_TOKEN"

Структура ответа

Полный ответ GET /api/v1/forecast содержит время получения данных и объект forecasts, где ключи соответствуют периодам.

{
  "fetched_at_utc": "2026-11-08T06:00:00+00:00",
  "forecasts": {
    "today": {
      "label": "Погода сегодня",
      "source_url": "https://www.gismeteo.ru/weather-gorodets-4334/",
      "resolution": "hourly",
      "hours": {
        "1794128400": {
          "timestamp": 1794128400,
          "time": "12:00",
          "sky": "Облачно",
          "temperature_c": 4.0,
          "wind_speed_ms": 3.0,
          "wind_gust_ms": 6.0,
          "wind_direction": "СЗ"
        }
      }
    }
  }
}

Пример иллюстрирует структуру и содержит условные значения. Фактический ответ может содержать больше временных точек и дней.

ПолеТипОписание
fetched_at_utcstringВремя формирования сохранённого набора, ISO 8601, UTC.
resolutionstringhourly для почасового прогноза или daily для дневного.
timestampintegerUnix timestamp в секундах.
temperature_cnumber или nullТемпература в °C. В дневном прогнозе может быть null, если отдельно указаны минимум и максимум.
temperature_min_c, temperature_max_cnumber или nullМинимальная и максимальная температура дневного прогноза.
wind_speed_ms, wind_gust_msnumberСкорость ветра и порывы в м/с.
wind_directionstring или nullТекстовое обозначение направления ветра.

Коды состояния HTTP

200Запрос успешно выполнен.

401Для обновления отсутствует или неверен токен.

404Указан неизвестный период или данные периода отсутствуют.

409Обновление уже выполняется.

502Не удалось загрузить или разобрать страницу источника при обновлении.

503Прогноз ещё не создан, файл данных недоступен или обновление через API отключено.

Ошибки возвращаются в формате JSON с полем detail.

Запуск сервиса

Установите зависимости, запустите первичную загрузку прогноза и поднимите ASGI-сервер:

python -m pip install -r requirements.txt
python main.py
python -m uvicorn api:app --host 127.0.0.1 --port 8000

Токен можно хранить в локальном файле .env в корне проекта. Сервис автоматически загружает его при обращении к API. Сгенерируйте собственное значение и сохраните его в файл:

# Windows PowerShell
Copy-Item .env.example .env
$token = python -c "import secrets; print(secrets.token_urlsafe(32))"
"WEATHER_API_REFRESH_TOKEN=$token" | Set-Content -Encoding ascii .env

# Linux / macOS
cp .env.example .env
python -c "import secrets; print('WEATHER_API_REFRESH_TOKEN=' + secrets.token_urlsafe(32))" >> .env

После изменения конфигурации перезапустите Uvicorn. Файл .env исключён из Git. Проверить настройку можно через GET /api/v1/health: поле refresh_enabled должно быть true.

Интерактивная схема доступна по адресу /api/swagger, машинно-читаемая спецификация OpenAPI — /api/openapi.json.
